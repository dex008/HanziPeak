# Attribution & licenses

## HSK vocabulary data

- **Source:** [jelleverheyen/hsk-vocabulary](https://github.com/jelleverheyen/hsk-vocabulary) (MIT),
  which builds on [elkmovie/hsk30](https://github.com/elkmovie/hsk30) for the HSK 3.0 lists.
- **Definitions:** derived from [CC-CEDICT](https://cc-cedict.org/), which is licensed
  **CC BY-SA 4.0**. Definitions derived from it must keep the same license and attribution.
- **Used for:** `app/lib/words.ts` (300 HSK 1 words). The first 100 glosses are hand-written;
  the remaining ~200 are selected from this data and machine-translated to Indonesian.

> Before a commercial/public release, have the derived glosses reviewed for license compliance
> (share-alike) and for linguistic accuracy.

## Translation

- Indonesian glosses for the 200 tail words were drafted with the
  [MyMemory](https://mymemory.translated.net/) API, then lightly normalised. **Not native-reviewed yet.**

## Typeface and art

- App art (seal icon, splash screens) is generated by `app/tools/make-branding.ps1` using the
  Windows system font **Microsoft YaHei** for the 字 glyph. The generated PNGs are original assets.
- No third-party icon packs, illustrations, or stock photos are bundled.

## TTS

- The app uses the **device's own TTS engine** at runtime — no audio is bundled and no third-party
  voice service is called.
- `app/tools/bake-audio.mjs` can generate neural audio with Edge TTS when the network allows. Edge's
  endpoint is unofficial; for production, use Azure's official TTS with your own key.
